# TE102 助听器用户内测问卷 — 网页版

基于 TE102 助听器（含电视伴侣 + APP）用户内测问卷制作的移动端优先网页问卷系统。

## 功能特性

- 📱 **移动端优先**：自适应手机屏幕，触控友好，支持横竖屏
- 🌐 **中英文双语**：右上角一键切换；首次访问根据用户 IP 自动判断默认语言（中国大陆/港澳台/新加坡→中文，其他→英文），IP 检测失败时回退到浏览器语言
- 📝 **39 道题 / 7 大维度**：人群定位、佩戴舒适、操作易用、声音清晰度、降噪啸叫、场景验证、整体留存
- 🎯 **多种题型**：单选、多选、是否、1-5 打分、0-10 NPS、分距离打分、打分+填空、家属评分、开放填空
- 🎚️ **分段式打分条**：1-5 分打分按钮占满整行宽度，按钮间无间隙连成一条，左右两端标注"非常差/非常好"，视觉直观
- 💾 **自动暂存**：答题过程自动保存到浏览器本地，刷新不丢失
- 📊 **多维导出**：
  - **JSON**：完整结构化数据，含题目元信息（含中英文双语文本）
  - **CSV**：一行一条记录，每道题一列，直接用 Excel 打开分析（含 BOM，中文不乱码）
  - **PDF / 打印**：浏览器原生打印，可另存为 PDF，格式化报告
  - **邮件**：一键调起邮件客户端，正文含答题摘要
- 📈 **实时统计**：提交后自动计算各维度平均分、NPS 推荐分，低于 3.5 分标红预警

## 本地运行

由于使用了 `fetch('questions.json')`，需要通过 HTTP 服务器访问，不能直接双击打开。

### 方式一：Python（推荐）
```bash
cd te102-survey
python -m http.server 8080
```
然后浏览器访问 `http://localhost:8080`

### 方式二：VS Code Live Server
安装 Live Server 插件，右键 `index.html` → Open with Live Server

## 部署到 GitHub Pages

1. 将本目录推送到 GitHub 仓库
2. 仓库 Settings → Pages → Source 选择 `main` 分支 / `root` 目录
3. 等待部署完成，访问 `https://<用户名>.github.io/<仓库名>/`

## 数据说明

### CSV 导出格式
- 第一行为表头：基本信息（受试者编号、日期、测试员等）+ 每道题一列（格式 `题号_分类`）+ 各维度平均分 + NPS
- 第二行为该受试者的全部答案
- 多份 CSV 可直接合并到同一 Excel 做横向对比

### 打分题编码
| 题型 | 编码 |
|------|------|
| 1-5 分打分 | 数字 1-5 |
| 0-10 NPS | 数字 0-10 |
| 分距离打分 | `1米内分\|3米外分` |
| 打分+填空 | `分数\|补充文字` |
| 多选 | 选项用 `\|` 分隔 |
| 单选/是否 | 选项文字 |

### 分析建议
- 按"分类"列汇总打分均值，低于 4 分的题对应迭代方向优先处理
- 人群定位题（Q01-Q09）用于分群与退货风险判断
- Q37（NPS）和 Q38（留存意愿）为核心满意度指标
- Q25（啸叫）、Q13（动态啸叫）为产品红线，需单独监控

## 修改问卷

编辑 `questions.json` 即可：
- `sections[]`：各大分类（`title` / `titleEn` 为中英文标题）
- `questions[]`：每道题，支持 `type` 字段：
  - `radio`：单选
  - `checkbox`：多选
  - `yesno`：是否
  - `rating1_5`：1-5 打分
  - `rating0_10`：0-10 打分
  - `rating_distance`：分距离打分（需 `subLabels` / `subLabelsEn`）
  - `rating_text`：打分+填空
  - `rating_yesno`：打分+是否
  - `family_rating`：家属打分
  - `text`：开放填空
  - `radio_text`：单选+填空
- 所有题目文本字段均有对应英文版（`text`→`textEn`、`options`→`optionsEn`、`category`→`categoryEn` 等），添加新题时建议同时填写中英文

## 技术栈

- 纯原生 HTML/CSS/JavaScript，无框架依赖
- LocalStorage 本地暂存与语言偏好记忆
- Blob API 客户端导出（无需后端）
- IP 地理定位（ipapi.co）自动判断默认语言，超时 5 秒回退浏览器语言
- 响应式设计，兼容 iOS Safari / Android Chrome
